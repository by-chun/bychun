雨下得很大，巷子里的灯光被水汽揉成一团模糊的橙色。他站在屋檐下，听着雨水敲打铁皮的声音。

手机屏幕亮了一下，是一条没有署名的消息。只有一行字：别回头。

他先是愣住，随后本能地想转身，又硬生生停住。

身后除了雨声，什么都没有。可他知道，那种被注视的感觉不会凭白出现。

他把手机塞回口袋，沿着墙根往前走。拐角处的便利店还亮着灯。

「要伞吗？」店员问。
