## 一、总体架构（用户反复强调，优先级最高）

**App 只是「AI 的大脑环境」，不是功能页面的堆砌。**

- App 提供：终端、容器（proot + 按需下载 rootfs）、原生能力（VPN/抓包/播放/注入）、工具集。
- 功能不写成固定页面；由 AI 判断后调工具完成。App 只负责执行与渲染。
- 用户原话：*"ai 输出对话都要配有窗口运行工具啊或者运行其他的，这样就不用固定了，ai 也能自己分辨是什么样子了"*
- 因此：**AI 的每次工具调用都要带「视图类型」**，App 用通用渲染器渲染，不预先给每个功能写界面。

## 四、待实现（顺序）

0. **流式输出（体验优先级最高）**：现在是一次性返回/等全部完成才显示，且请求常卡住。
   - 请求改 `stream: true`，解析 SSE（`data:` 行，取 `delta.content`）
   - 逐字追加渲染（打字机效果），而不是等整段
   - 收到 `delta.tool_calls` 时先收齐参数 → 渲染视图卡 → 继续下一轮
   - 首包等待时显示「思考中…」，超时/失败给可重试提示，不无响应干等
1. **通用渲染器**：`view` → 组件，先做 `list` / `detail` / `stream` / `confirm` 四种。
2. **抓包数据层**：VPN/DNS 采集 + 应用归属（uid→应用名）+ 存储。
3. **抓包 UI 接入**：流 → 列表 → 详情，按定稿渲染。
4. **CA 证书**：生成自签 CA → 装进系统信任区（需 root，重启生效），之后才能解 HTTPS 明文。
5. **AI 工具**：`capture_list` / `capture_read`（带确认）/ `capture_to_script`。
6. **播放器**：`play_media` 工具 + 内嵌媒体卡；视频/音乐完整播放页。
7. **插件系统**：文件夹式管理（不自动分组）、配置页按类型生成字段、可存订阅进度。
8. **注入**：只做三种 —— 抓包层（请求重写）/ Xposed 模块 / Zygisk；**不做开机自启**，只在用户丢脚本时启动。
   - **模块支持热更新配置**：hook 侧每次从 `/data/adb/modules/<id>/` 下读 `config.json` 与 `scripts/`，
     不在 so/apk 里写死规则。
   - **写权限边界**：AI 默认对模块目录**只读**。只有用户明确说「写进去 / 加到模块里」时才写，
     而且每次写都弹确认；不允许 AI 自作主张把内容写进模块。
   - 生效时机：配置改了，目标 App 下次启动（或 frida 脚本 reload）后生效；二进制本身不热替换。
   - 抓包→存成脚本→放进模块 `scripts/`，就是“实时更新”的效果。
   - Xposed 侧同理：LSPosed 模块的配置也走文件，AI 可直接改。
9. **VPN**：订阅 URL 导入、节点选择、↻ 更新、存成脚本下次复用。

## 五、已确认的产品细节

- **AI 输出必须流式**：一个字一个字出现，段落结束再补视图卡，最后收敛结尾；不允许长时间空白无响应。
- **不内置任何镜像**：容器全部按 URL 下载（Alpine/Ubuntu/Debian 都一样），APK 不带 rootfs。
- 容器默认绑定 `/sdcard`；容器内可通过 `gget <url> <name>` 装新容器（`/opt/envs` 映射 `filesDir/envs`）。
- 终端内 `gsu <命令>` 走宿主 su；root 类操作每次都确认。
- 插件页 = 真文件夹（用户自己分或让 AI 分），不要自动分类。
- 视频订阅脚本记录：当前集数、播放位置、倍速；下次拖脚本进来从原处继续。
- 音乐脚本记录播放列表、循环模式、当前曲目与进度。
- 抓包明文内容发给 AI 前必须弹确认（含 Token/Cookie 提示）。
- **AI 不主动写模块/系统文件**：模块目录（`/data/adb/modules/**`）默认只读，用户明确要求才写，每次确认。

## 六、技术约束（踩过的坑）

- **proot 嵌套不可行**：本设备 `PTRACE_TRACEME` 直接崩（signal 11/6），不要在容器内再起 proot；`gsu` 走广播是唯一可靠路径。
- 容器内 uid=0 是伪 root（`-0`），改不了 `/data` 权限；`/data` 全盘只有 root 能读。
- `/data/梧春` 已打自定义 SELinux 标签 `rowan_data_file` + KernelSU 模块 `rowan-data-access`（重启保留）。
- `/sdcard` 是 noexec：脚本能用 `sh 路径` 跑，ELF 不能直接执行。
- 从 app 私有目录 exec 被 W^X 拦；proot 自身靠 loader 绕过，自编译二进制要放进 rootfs。
- CA 证书路径随版本：Android 13- 用 `/system/etc/security/cacerts`，14+ 走 APEX。
- 抓包只拦 DNS 不影响上网；要看 HTTPS 明文必须先装 CA。
